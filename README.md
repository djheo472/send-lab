# SEND lab

Public website for the Sensor / Energy / Nanotechnology Device Laboratory, led by Prof. Deokjae Heo at Kumoh National Institute of Technology.

## Updating the website

Each page is an ordinary HTML file. Edit a page in GitHub and commit the change; GitHub Pages publishes it automatically. Images and styles are stored alongside the pages. No administrator password, server or database is required.

- `professor.html`: biography, appointments and honors
- `research.html`: research areas and figures
- `members.html`: members
- `publications.html`: publications, newest first
- `teaching.html`: courses by semester
- `contact.html`: contact details and office map

Keep only content intended for public viewing in this repository. Source files and commit history are public. Research figures remain subject to their respective rights.

GitHub Pages: deploy from the `main` branch, `/ (root)` folder.
